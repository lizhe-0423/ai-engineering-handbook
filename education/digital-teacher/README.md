# 数字名师

[← 教育目录](../README.md)

数字名师是一种教育业务场景。学校或教育机构把课程资料、教师经验和教学规则整理成可调用的内容，学生可以在固定课程范围内获得持续服务。

一个头像和一段克隆声音只能解决呈现问题。回答质量取决于教师怎样拆题、怎样提示，以及什么时候把问题交回真人教师。这些经验需要写成清楚的规则，并和教材、讲义、题库一起维护。

数字名师通常包含四类能力。

- [答疑](qa.md)处理学生的具体问题，并根据学科和课程组织讲解。
- [智能批改](grading.md)依据评分标准检查作答，给出分项结果和修改建议。
- [个性化学习](personalized-learning.md)根据学习记录判断下一步适合学什么。
- [成长陪伴](learning-companion.md)帮助学生维持目标和节奏，同时守住安全边界。

这四类能力可以共用教师知识和学生档案，服务目标却不同。答疑解决眼前的问题，批改解释一次作答，个性化学习安排后续路径，成长陪伴处理更长时间里的计划和反馈。
