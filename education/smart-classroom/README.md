# AI 智慧课堂

[← 教育目录](../README.md)

AI 智慧课堂关注正在发生的教学。教师仍然决定教学目标、课堂节奏和学生评价，AI 可以协助准备材料、处理互动信息，并在课后整理课堂记录。

课堂里的系统要比普通聊天工具更克制。学生名单、声音、图像和作答都可能进入系统，学校需要提前说明采集范围和使用方式。课堂建议也要允许教师忽略或纠正，系统不能越过教师直接改变正式评价。

目前这组文章先讨论一个场景。
