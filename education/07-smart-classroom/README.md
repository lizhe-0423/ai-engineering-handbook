# AI 智慧课堂

[← 教育目录](../README.md)

这一章研究 AI 怎样进入一整节课。教师何时调用，学生怎样参与，得到的课堂证据怎样影响后续教学。答疑、批改和视频讲解都可以被课堂使用，本章重点是这些能力与教学过程的衔接。

## 政策背景

2026 年《“人工智能+教育”行动计划》提出，加强课前、课中、课后的智能教学系统应用，探索人机协同教学，并开展人工智能循证教研。组织实施部分要求各地各校制定符合自身实际的方案。正文据此讨论课堂应用的推进方向，不将其概括成每节课必须使用 AI。[教育部等五部门原文](https://hudong.moe.gov.cn/srcsite/A16/s3342/202604/t20260410_1433240.html)

文件落款为 2026-04-02，网页发布日期为 2026-04-10，文号为教科信〔2026〕1号。

人工智能通识课程与学科教学中的 AI 辅助分别讨论。前者教授 AI 知识，后者用于支持具体教学活动，课程要求与应用安排不能混成同一件事。

## 按教学环节整理选题

Kimi 的[智慧课堂资料页](https://www.kimi.com/showcases/deep-research/ai-classroom-transformation)按六类教学环节组织内容，可以作为梳理课堂活动的线索。其中涉及的工具和学校案例仍以各自的原始资料为准。

下面这张表用来说明可以研究哪些课堂活动。它不代表一套经过课堂实验的固定方案。

| 环节 | 可以研究的应用 | 需要解释的问题 |
|---|---|---|
| 导入 | 情境素材、诊断提问、已有知识回顾 | 素材怎样对应目标，教师怎样确认内容 |
| 讲解 | 动态板书、公式与图形可视化、即时答疑 | 讲解怎样与课堂进度同步，学生怎样追问 |
| 方法引导 | 分层提示、解题策略、学习任务支架 | 哪一步给提示，怎样保留学生自己的推理 |
| 合作探究 | 小组问题、资料检索、实验与模拟 | 怎样区分模型建议、小组结论和可核对证据 |
| 展示交流 | 作品整理、论据对照、同伴反馈 | 怎样保留学生原作与教师评价标准 |
| 总结评价 | 随堂作答整理、问题归纳、后续练习建议 | 哪些结果支持调整教学，哪些需要继续观察 |

教师决定哪些内容进入公共展示、何时暂停或修订。课堂反馈保留题目、实际作答和处理结果，避免只留下一个笼统的“参与度”分数。

## 从课前到课后

课前，准备教学目标、资料和活动方案，核对 AI 生成候选。课中，围绕当前活动调用工具、收集学生作答，教师据此决定继续、追问或补充讲解。课后，整理未解决问题与学习任务，再联系答疑、批改和个性化学习。

实现这样的课堂系统，需要处理课程上下文、教师端控制、学生端互动，以及板书与媒体同步。活动状态和结果也要保存下来。大屏、平板等终端按学校的实际条件选择，硬件清单本身不能代替教学方案。
