# AI Native

[← 返回首页](../README.md)

本仓库把 AI Native 理解为一种研发方式。Agent 进入需求理解、编码、验证和交付过程，团队同时补上运行环境、权限、安全与可观测能力，让它能够参与真实的软件工程任务。

这个栏目以阿里公开的 [AI Native 研发范式实践手册](https://ai-native.alistatic.com/app/ainativeinfra/ai-native-handbook-web/index) 为调研起点。手册从实践案例讲到落地挑战，随后展开企业级 AI 研发基础设施。本仓库会沿着这些问题继续研究，用自己的工程语言重新组织内容，不复制原文，也不把厂商方案直接当成通用答案。

## 内容地图

| 主线 | 准备讨论的内容 |
|---|---|
| 研发范式实践 | 人与 Agent 怎样分工，怎样准备上下文，怎样让生成、验证与交付连成完整过程 |
| 工程落地挑战 | 开发环境怎样适配 Agent，平台能力怎样升级，提效怎样衡量，组织怎样接住新的协作方式 |
| 企业级基础设施 | Agent Harness、企业知识与工具、Sandbox 与 Coding 环境、身份权限、安全防护和可观测 |

## 后续写法

后续文章会从具体问题开始，一篇只处理一个工程主题。官方材料用于核对概念和公开方案，项目经验用于解释选择条件、失败边界与落地代价。内容完成以后再加入链接，栏目首页不提前放置空入口。
