# AI Native

[← 返回首页](../README.md)

Agent 开始参与需求理解、编码、验证和交付以后，研发流程也要跟着变化。这个栏目关注任务怎样交给 Agent，工程环境怎样约束执行，以及结果怎样验收。

## 文章

- [AI Native 到底改变了什么](what-ai-native-changes.md)从一项普通研发任务讲起，说明任务契约、上下文装配、验证和运行治理发生了哪些变化。
- [Agent Harness 怎样让长任务跑到结束](agent-harness-long-running-task.md)解释上下文、工具调用、检查点、验证和人工审批怎样组成持续运行的任务。
- [企业知识和工具怎样交给 Agent](enterprise-context-and-tools.md)集中说明规则、知识、Skill 的组织与加载、工具契约，以及已有协作入口的接入。
- [Agent 在哪里运行](agent-runtime-environment.md)说明 Sandbox 与 Coding Environment 怎样准备可隔离、可重建的任务环境。
- [身份、权限和 Guardrail 怎样约束 Agent](agent-identity-policy-guardrail.md)梳理复合身份、委托、短期凭证、策略判断和行动检查。
- [怎样看清一次 Agent 执行](agent-observability-and-evaluation.md)讲运行轨迹采集、故障定位与证据管理。任务评分、轨迹约束和版本对照另见 [Agent 评测](../agent-learning-path/agent-evaluation.md)。
- [团队怎样把 Agent 放进真实研发流程](agent-team-adoption.md)讨论任务分流、自主程度、责任划分、提效衡量与试点进退条件。
