# AI Native 栏目设计

## 目标

在仓库首页增加可见的 AI Native 一级入口，并建立 `ai-native/` 栏目首页。读者能够从根目录进入栏目，了解后续内容范围，也能回到阿里官方手册核对原始材料。

## 材料边界

栏目以阿里公开的《AI Native 研发范式实践手册》为主要起点。手册共 68 页，目录包含研发范式实践案例、实践中的挑战和企业级 AI 研发基础设施。基础设施部分继续讨论 Agent Harness、运行环境、可信安全与可观测。

仓库不会复制手册正文，也不会把官方目录逐章改写。后续文章结合本仓库已有的 Agent、数据工程和企业平台内容，重新组织问题、工程选择与适用边界。涉及官方定义时保留原始链接，涉及作者判断时明确写成工程分析。

## 页面结构

根目录 `README.md` 增加 AI Native 专题行，描述研发范式、Agent Harness、运行环境、可信安全与可观测，并链接到 `ai-native/README.md`。

`ai-native/README.md` 先介绍 AI Native 在本仓库中的含义，再展示三条内容主线。

1. 研发范式实践，关注人和 Agent 怎样共同完成真实研发任务。
2. 落地挑战，关注环境、验证、平台升级、提效边界与组织能力。
3. 企业级基础设施，关注 Agent Harness、知识与工具、运行环境、身份权限、安全防护和可观测。

栏目首页只链接已经存在的页面。尚未写成的主题使用文字说明，避免出现无法打开的空入口。

## 验证

检查根目录入口能够解析到栏目首页，检查栏目首页中的官方链接可访问，并运行 Markdown 差异检查与中文文风检查。
