# FDE 案例集第一版设计

用户已确认：把现有经验写成仓库中的案例教程，教育是其中一组，参考公开教育网站和授权的本地 notes；每完成一章报告；以后用书的入口替换主页 Product Experience。

定位：《FDE 案例集：从业务问题到 AI 应用交付》，Blueberry 著。主要读者是开发者和教育技术团队；每个案例从业务问题走到实现、评测与交付。当前教育卷完整覆盖名师经验、教学流程、课程答疑、拍照搜题、作业批改、评测、交付，以及可复用案例库。其他领域只在路线图记录，不凭空扩写为作者经历。

章节：00 前言；01 FDE 方法；02 教师经验；03 教学流程；04 RAG 答疑；05 拍搜；06 批改；07 评测；08 交付；09 案例库。各章原创例题和图，引用公开背景与一手技术文档。

材料边界：本地 notes 仅供理解问题，未验证的构想不当成实现事实。内部图片链接不访问、不搬运；具体公司系统结构、内部业务参数与真实数据不写入发布文件。仅保留通用问题、公开背景和重新设计的示例。

配套：Python 标准库离线示例，覆盖课程资料过滤、引用检查、图像转写不确定性路由、评分量规与证据校验、教师发布门槛；Ollama 为明确启用的可选模型适配。离线结果不能证明模型或教育效果。

交付：本地 Git 仓库、Markdown 单章与合订版、模板、合成数据、可运行示例、真实验证结果、来源账本与作者待核对清单。当前先形成可审阅稿；不直接更改 GitHub main/master 或用户现有主页。
