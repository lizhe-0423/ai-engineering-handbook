# AI Agent 图解书

[← AI Agent 学习路线](../README.md) · [离线 HTML 入口](index.html)

从具体问题理解 Agent。28 个主题与 2 篇架构补充，每篇采用对应机制的图形，并比较三种不同情况。HTML 版可以切换演示、检查理解、搜索章节；下面的 Markdown 图文版可以直接在 GitHub 阅读。

离线使用时，下载整个 `eli5` 目录并打开 `index.html`。HTML 无需联网或安装依赖。GitHub 仓库页面通常显示 HTML 源码，请使用下面的图文链接，或在本地浏览器打开。

## 维护图解

讲解内容在 `source/content.py`，各主题的机制图在 `source/diagrams.py`，页面生成器在 `source/build.py`（第 17 篇使用 `source/redesign_17.html` 独立模板）。修改后执行 `python3 agent-learning-path/eli5/source/build.py`，同步生成 HTML、Markdown 和 SVG。页面样式与交互分别在 `guide.css`、`guide.js`。

运行 `python3 agent-learning-path/eli5/source/check.py` 检查产物、链接与内容对应关系。浏览器验证方法见 [维护说明](source/README.md)。
