# AI Agent 学习路线

[← 返回首页](../README.md)

学习 AI Agent 可以从一个能够调用模型的应用开始，随后逐步加入知识检索、工具调用、状态管理和评测。每一步都解决一个明确问题，比一开始搭建复杂的多智能体系统更容易理解。

## 第一阶段　大模型应用基础

先熟悉模型调用、消息结构、流式输出和结构化结果。重点理解上下文长度、随机性、提示词与模型能力之间的关系。

## 第二阶段　知识与工具

学习 RAG 的文档处理、检索和答案生成链路，再让模型调用搜索、数据库与业务接口。工具输入需要明确的数据结构，执行结果也要经过校验。

## 第三阶段　Agent 系统

加入任务拆解、状态保存、短期记忆和人工接管。随后研究单智能体与多智能体的适用边界，以及长任务中的重试、超时和恢复。

## 第四阶段　可观测性与评测

建立日志与 Trace，保存模型调用、工具参数、运行结果和业务状态。再用任务级评测比较 Agent 的新旧版本，检查一次修改解决了什么，又让哪些原有任务发生了退化。

- [Agent 评测怎样判断一次修改有没有真的变好](agent-evaluation.md)

## 第五阶段　生产治理与安全

处理身份、权限、成本、并发、发布和故障恢复。Agent 对外提供服务以后，还要保护系统提示词、Skill、知识内容和工具能力，识别跨会话与跨账号的持续滥用。

- [Agent 服务怎样防止能力被批量提取](agent-service-security.md)
