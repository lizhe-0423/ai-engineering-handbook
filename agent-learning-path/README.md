# AI Agent 学习路线

[← 返回首页](../README.md)

学习 AI Agent 可以从一个能够调用模型的应用开始，随后逐步加入知识检索、工具调用、状态管理和评测。每一步都解决一个明确问题，比一开始搭建复杂的多智能体系统更容易理解。

## 第一阶段　大模型应用基础

先熟悉模型调用、消息结构、流式输出和结构化结果。重点理解上下文长度、随机性、提示词与模型能力之间的关系。

## 第二阶段　知识与工具

学习 RAG 的文档处理、检索和答案生成链路，再让模型调用搜索、数据库与业务接口。工具输入需要明确的数据结构，执行结果也要经过校验。

## 第三阶段　Agent 系统

加入任务拆解、状态保存、短期记忆和人工接管。随后研究单智能体与多智能体的适用边界，以及长任务中的重试、超时和恢复。

## 第四阶段　工程化

建立日志、链路追踪、测试集和评测指标。最后再处理权限、成本、并发与部署，让 Agent 从演示程序变成可以维护的产品。
