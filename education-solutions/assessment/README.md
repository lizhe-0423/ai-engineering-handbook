# 智能作业与教育评价

[← 教育目录](../README.md)

这一场景处理练习、模考与作答评价。产品需要先固定任务与评分要求，再保存原始作答，依据评分标准找出证据，把判断、反馈和不确定项交给学生或教师。客观题可以更多依赖规则，开放性任务需要保留教师的专业判断。

教育评价会影响学生机会，也会反过来影响教学安排。分数无法解释、图片识别错误、量规版本用错，都会直接影响评价结果。系统必须保留题目、原始作答、量规版本、模型判断和人工修改，才能让一次结果可以复核。
