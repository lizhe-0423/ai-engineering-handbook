# 学校运营与教育治理

[← 教育目录](../README.md)

学校里有大量高频咨询和跨系统事项。学生想知道课程变更，教师要查办事要求，校务人员还要核对身份、材料和处理状态。学校引入 AI 以后，也要组织教师培训、成果审核和后续支持，这些工作同样需要明确责任和验收方式。

校园服务 Agent 要把回答问题和办理事项分开。前者可以从已发布制度中检索答案，后者需要身份、权限、参数确认和操作回执。模型负责理解表达与组织步骤，业务系统仍要用确定性的接口校验规则。
