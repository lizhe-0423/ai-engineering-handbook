# AI 智慧课堂

[← 教育目录](../README.md)

AI 智慧课堂关注正在发生的教学。这里的系统要跟上课件、讲解、提问和教师指令，还要面对网络抖动与设备差异。课前生成一段视频属于内容生产，能根据课堂状态做出受控响应，才进入实时教学。

教师仍然决定教学目标、课堂节奏和学生评价。AI 可以承担固定讲解、整理互动信息和课后归档，任何临时回答都要受到课程范围与风险规则约束。课堂里的错误会被同时放大给许多学生，接管按钮、静态备用内容和断网降级都属于主流程。

学生名单、声音、图像和作答可能进入系统，采集范围与保存期限需要提前确定。没有教学需要的数据不进入模型，课堂建议也不能越过教师改变正式评价。
