# AI 智慧课堂

[← 教育目录](../README.md)

AI 智慧课堂关注正在发生的教学，既包括实时讲解与问答，也包括学生能够操作的课堂工具。系统需要适应教师指令、网络条件和设备差异。预先生成的内容怎样进入课堂，操作后的结果是否正确，都需要单独检查。

教师仍然决定教学目标、课堂节奏和学生评价。AI 可以承担固定讲解、整理互动信息和课后归档，任何临时回答都要受到课程范围与风险规则约束。课堂里的错误会同时影响许多学生，教师应能随时停止或接管系统，静态备用内容和断网降级也要提前准备。

学生名单、声音、图像和作答可能进入系统，采集范围与保存期限需要提前确定。没有教学需要的数据不进入模型，课堂建议也不能越过教师改变正式评价。

这里讨论课堂运行、互动工具制作，以及录制课程的资料加工。

- [教师怎样用 AI 制作互动教学工具](interactive-teaching-tools.md)从函数图像工具出发，讨论教学目标、代码生成、受限预览、计算检查、固定版本发布与课堂备用方案。
