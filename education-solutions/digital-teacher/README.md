# 数字名师与智能学习服务

[← 教育目录](../README.md)

这类产品面向学生的具体学习过程。学生带着一道题、一次练习结果或一个阶段目标进入系统，产品需要在当前课程内组织材料，再按合适的教学策略给出下一步。

数字名师是常见的产品包装，背后至少有课程知识、学生状态和教学策略三部分。头像与合成声音解决呈现问题，无法替代这些业务能力。只接一个通用大模型，产品通常会答得很勤快，却很难说明依据，也不知道学生此刻需要提示还是完整答案。

这里从课程答疑与学习记录写起，再讨论具体学习任务的组织。

- [数字名师怎样回答一道题](qa.md)处理题目识别、固定题库拍搜、知识检索、分步讲解和拒答边界。
- [在线答疑怎样接入人工坐席](human-handoff.md)处理主动转人工、会话接管、坐席分配和消息可靠性。
- [个性化学习从学习记录开始](personalized-learning.md)处理学习者状态、内容选择和推荐后的反馈。
- [学生档案怎样成为长期记忆](student-profile-memory.md)处理 Markdown 档案、会话压缩和跨会话更新。
- [AI 背单词怎样安排下一次复习](vocabulary-review.md)处理词义与任务区分、独立回忆证据、记忆模型和到期队列。

备考中的限时作答与成绩复盘，见[AI 备考怎样组织练习、模考与复盘](../assessment/exam-practice.md)。
