# 教师智能助手

[← 教育目录](../README.md)

教师智能助手服务教师课前、课中和课后的工作。它可以查课程标准与校本资料，整理教案初稿，生成分层练习，也可以把课堂记录变成待确认的学情线索。产品的价值取决于它是否接进教师原有流程，生成几页看起来完整的文档远远不够。

教师经验经常藏在旧教案、批注、题目取舍和课堂调整里。系统要保留资料来源与版本，让教师看得见哪些内容来自正式文件，哪些只是模型建议。教师修改后的结果也不能不加区分地回流，个人偏好、学科共识和学校规则需要分层维护。
