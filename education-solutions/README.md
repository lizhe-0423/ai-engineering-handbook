# AI 教育解决方案

[← 返回首页](../README.md)

这一部分整理 AI 教育公司的产品与工程问题。文章从一次真实业务请求怎样进入系统写起，讲清数据从哪里来，模型和 Agent 怎样配合，教师或校务人员在哪一步确认结果，以及产品上线后该看哪些指标。

这里不会按大模型、数字人、知识图谱等技术名词分目录。同一种技术可能同时服务答疑、备课和校务咨询，业务责任却完全不同。目录按使用者正在完成的工作划分。

下表提供各场景的起读文章，完整文章列表放在对应的场景目录中。
