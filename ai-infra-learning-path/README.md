# AI Infra 学习路线

[← 返回首页](../README.md)

AI Infra 关注模型怎样高效、稳定地运行。学习时可以从一次本地推理开始，再逐步理解计算资源、推理引擎、分布式服务和生产环境中的调度问题。

## 入门

- [初识 AI Infra，从一次模型请求看起](what-is-ai-infra.md)沿请求执行认识模型服务、计算设备与数据传输，区分显存容量、算力、带宽，以及吞吐和用户等待时间。

## 第一阶段　模型与计算基础

理解 Transformer 的计算过程、模型参数与显存之间的关系，并熟悉常见精度格式、量化方法和模型文件格式。

- [模型参数是怎样训练出来的](how-model-parameters-learn.md)从两个参数的一次更新理解损失、梯度与优化器，再区分微调、SFT、RL、LoRA 和蒸馏。
- [模型架构怎样决定计算与显存开销](model-architecture-resource-budget.md)沿 token 的计算路径理解注意力、前馈网络与 KV 缓存，再看 GQA 和 MoE 怎样改变资源预算。

## 第二阶段　推理服务

学习模型加载、批处理、KV Cache 和流式输出。对比不同推理引擎怎样安排请求，并观察吞吐量、首字延迟和显存占用。

- [推理与训练为什么需要不同的资源预算](inference-and-training-workloads.md)从输入处理、逐步生成和请求排队，延伸到多轮 Agent、反向传播与训练状态，说明负载怎样改变时延和容量。

## 第三阶段　分布式与资源调度

继续学习张量并行、流水线并行和多机通信。服务规模扩大以后，还要处理 GPU 调度、弹性扩缩容和多模型资源隔离。

## 第四阶段　生产运行

为推理服务建立监控、限流、故障恢复和容量规划。把模型版本、服务配置和性能数据放进统一流程，才能持续比较优化结果。
