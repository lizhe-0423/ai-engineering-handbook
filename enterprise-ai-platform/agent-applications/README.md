# 智能体服务与业务编排

[← 企业级 AI 生产平台](../README.md)

智能体应用把模型能力接入企业流程。它可以识别用户需求、查询知识、调用业务系统，并把复杂任务分成多个步骤执行。

企业问答通常是最早落地的场景。系统先判断问题类型和服务范围，再决定直接回答、查询资料、创建任务或转交人工。涉及订单、审批和信息修改时，需要经过身份校验与权限检查，不能只凭自然语言指令执行。

业务编排需要记录每一步输入、工具调用和结果。任务失败后可以从明确的节点重试，人工人员也能看到已经发生的操作。系统能力越强，越需要限制可调用工具、执行范围和自动化程度。
