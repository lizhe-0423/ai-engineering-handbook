# 数据工程与智能标注

[← 企业级 AI 生产平台](../README.md)

数据工程负责把分散的业务资料变成可以训练、检索和评测的数据。来源可能是文档、表格、图片、音视频，也可能来自业务系统中的持续记录。

数据进入平台以后，需要经过解析、清洗、去重、分类和版本管理。人工标注仍然重要，AI 可以先完成预标注和相似内容归并，再由业务人员处理边界样本。这样能够减少重复劳动，也不会把模型判断直接当成最终结果。

数据质量需要贯穿整个过程。平台应当记录数据来源、处理步骤、修改历史和使用范围。当原始资料更新或撤回时，下游训练集、知识库与评测集也要能够同步追踪。

下面三篇文章分别处理训练数据怎样完成生产与归档、业务变化怎样进入下游，以及线上反馈怎样变成可用数据。

- [一份多模态训练数据怎样完成生产与归档](multimodal-training-data-production.md)讨论数据集版本、标注任务、质量验收、异步归档和训练交付。
- [CDC 怎样捕获数据库变更](cdc-change-capture.md)讨论日志捕获、事务边界、全量快照、增量衔接和适用条件。
